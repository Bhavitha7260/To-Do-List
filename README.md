To-Do List CLI App

Project Description

The To-Do List CLI App is a simple Python application that helps users manage their daily tasks through a command-line interface. Users can add new tasks, view all available tasks, and remove completed or unwanted tasks. The application uses a Python list to store tasks while the program is running.

Features

- Add Tasks: Add new tasks by entering their names.
- View Tasks: Display all tasks with serial numbers.
- Remove Tasks: Delete a task by entering its number.
- Input Validation: Handle invalid task numbers and inputs.
- Simple Interface: Easy-to-use menu-driven program.

Technologies Used

- Python 3
- Python lists
- Functions
- Loops and conditional statements
- Exception handling

How to Run

1. Install Python on your computer.

2. Open the project folder in Visual Studio Code.

3. Save the Python program as "todo_list.py".

4. Open the terminal in VS Code.

5. Run the following command:
   
   python todo_list.py

Usage

1. Select option "1" to add a task.
2. Select option "2" to view all tasks.
3. Select option "3" to remove a task.
4. Select option "4" to exit the application.

Limitations

Tasks are stored in memory and will be lost when the program closes. File handling can be added to save tasks permanently.

Conclusion

The To-Do List CLI App demonstrates basic Python programming concepts, including lists, functions, loops, conditional statements, and exception handling. It provides a simple way to organize daily tasks.
